AMBAR Rental Program Simulator — VERSION 1 (archived 2026-06-25)
================================================================
This is the full-featured simulator that was LIVE at ambar-rentalprogram.com
before V2 (cash-only) replaced it.

V1 includes: Unit Types, Down Payment, Bank Financing, Revenue Projection,
Profitability & Returns (cash + financed), Projection Assumptions, Tax Benefits.

To restore V1 as the live site: copy v1/index.html back to the root index.html
and redeploy. Also reachable at /v1/ if this folder is deployed.
